# Eagle X Control Panel

لوحة إدارة Eagle X لإدارة معرّفات الأجهزة، وحالة التفعيل، وبيانات اشتراك IPTV من لوحة واحدة.

## المتصل حاليًا

- تسجيل دخول المسؤول عبر Supabase Auth.
- حفظ الأجهزة وحالات التفعيل وتاريخ الانتهاء في قاعدة بيانات Eagle X Control.
- حفظ مصدر فيديو IPTV مع الجهاز في قاعدة البيانات: Xtream Codes أو M3U.
- يرسل التطبيق معرّف الجهاز إلى نقطة التحقق العامة `device-status`، ولا يحتاج العميل إلى إدخال كود تفعيل.
- عند تفعيل الجهاز وإضافة مصدر IPTV صالح، تعيد نقطة التحقق بيانات الاشتراك للتطبيق.
- إيقاف الجهاز أو انتهاء المدة يمنع نقطة التحقق من تسليم مصدر IPTV.
- بيانات الصوت الخارجي M3U في واجهة اللوحة ما زالت محلية في المتصفح ولم تُربط بعد بجدول `external_audio_sources`.

## طريقة الاستخدام

1. افتح قسم **الأجهزة والتفعيلات**.
2. أدخل معرّف الجهاز الظاهر في شاشة Eagle X عند العميل.
3. اختر الحالة **نشط** وحدد تاريخ الانتهاء.
4. أدخل بيانات IPTV في قسم الفيديو: Host واسم المستخدم وكلمة المرور، أو رابط M3U.
5. اضغط حفظ. عند ضغط العميل **تحقق من التفعيل**، يستلم التطبيق بيانات IPTV ويضيف الاشتراك تلقائيًا.

## الأمان

- بيانات اعتماد المسؤول محمية بتسجيل الدخول والتحقق من صلاحية المسؤول في Edge Function `admin-api`.
- لا تضع مفتاح Supabase السري أو مفتاح `service_role` في الواجهة؛ تستخدم الواجهة مفتاحًا عامًا فقط.
- بيانات IPTV تُقرأ وتُكتب عبر Edge Function باستخدام صلاحية الخادم، ولا تُقرأ مباشرةً من الجداول العامة.
- معرّف الجهاز هو أساس الربط بين التطبيق والاشتراك؛ لا تشاركه علنًا.

## النشر

يمكن نشر الواجهة من GitHub Pages عبر **Settings → Pages**. يلزم أن تظل Edge Functions في مشروع Supabase `Eagle X Control` فعالة حتى تعمل إدارة الأجهزة والتحقق من التفعيل.
